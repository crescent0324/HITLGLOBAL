# 本機體驗環境驗收紀錄

驗收日期：2026 年 10 月 3 日。所有住民與回報均為虛構；本次操作不納入論文既有實驗結果。

## 自動化測試

`python -B -m unittest -v test_care_console`：20 項通過，執行時間 38.338 秒。測試使用暫存資料庫、離線替代服務，禁止外部網路連線。

| 控制需求 | 實際檢查 |
|---|---|
| 登入與本機限制 | 未登入拒絕、外部 Host／IP 拒絕、CSRF 與跨來源拒絕、錯誤密碼與頻率限制、登出失效 |
| 住民查看權限 | 五種角色分別取得 6／6／2／1／1 位住民；家屬無法讀取或操作其他住民 |
| 工作人員權限 | 照服員不能設定評估狀態；家屬不能匯入、回報或接手案件 |
| 人工案件 | 同一住民跨角色共用對話；人工接手後不自動恢復；只有接手帳號可回覆或結案；人工回覆保存帳號身分 |
| 問答來源與通道 | 服務問題取得固定資料摘要、1966 入口與來源；模擬 LINE 帳號有來源紀錄；未呼叫模型或真實 LINE |
| 高風險流程 | 指定倒地情境進入待接管，未建立一般生成工作 |
| CSV 品質 | 無效資料整批拒絕、未知住民拒絕、NaN 拒絕、時間需含時區且不能任意填未來時間 |
| 重複與更正 | 同識別碼同內容略過；衝突時整批回滾；舊回報不取代最近觀察；缺值維持未知 |
| 住民與床位分離 | 已占用床位拒絕覆寫；轉至空床後原紀錄與家屬權限仍對應同一住民 |
| 授權變更 | 撤銷授權後，既有登入工作階段也不能再取得該住民資料 |
| 保存與備份 | 重啟未重新植入資料；雙資料庫快照完整性通過，能在全新目錄載入案件與住民；備份未含 API 設定及 session.key |
| 資料目錄識別 | 已有但未標識的資料目錄拒絕使用，避免混入其他系統 |

## 瀏覽器操作

實際操作家屬登入→固定喘息摘要→要求人工→護理師登入→接手→人工回覆→結案。確認家屬畫面只有 R001，護理師可看到全部 6 位住民。重啟程式後，原人工處理中的案件仍保存。

在匯入頁貼入一筆明確虛構的 R002 紀錄，結果為新增 1 筆、略過 0 筆。回到看板，可看見此筆來源為「院內測試 CSV 匯入」及其觀察時間。

另以 390 × 844 的瀏覽器寬度檢視看板，導覽、卡片與表單採手機配置，完成後恢復原視窗尺寸。未代替實際護理師進行使用性評估。
