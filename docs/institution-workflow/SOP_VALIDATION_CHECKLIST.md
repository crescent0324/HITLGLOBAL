# 機構SOP訪談與核對表

本表全部預設「待確認」，不預填符合。來源層級見 [SOURCES](SOURCES.md)。訪談收集的是誰做什麼、需要什麼資訊與可用例外程序；不要求提供真實住民、帳號、聯絡人、申訴原文或內部系統截圖。

## 場次安排與使用方式

探索性建議找不同班別護理師至少2位、護理長1位；機構負責窗口、照服員、社工、行政及IT分別補核對相關事項。這是招募建議，沒有統計代表性保證；人員不足時如實記錄未覆蓋職務。護理長與部屬可分開訪談，避免主管在場取代第一線的意見。

每場建議60～75分鐘：說明與同意、現行工作敘述、虛構任務、方案比較、回饋與核對。這是研究場次安排，與案件回覆／接班時限無關。受訪者可跳題或退出，不用績效考核口吻要求答對。錄音、錄影及截圖分別取得同意，未同意就不錄；訪談筆記以代碼記錄，保存範圍、期限與可讀者先約定，沒有同意不對外發布。

若用於論文或正式對外研究，依所屬單位程序確認倫理審查及同意需求，本文件不自行判定免審。本輪未招募、訪談或取得任何參與者資料。

主持人先問現行做法，操作虛構任務時請人員想出聲，再出示候選方案。不能先講「系統這樣比較安全」誘導選擇。卡住時先記錄，再以標準提示協助；協助完成與獨立完成分開。

| Q12 | 家屬申訴通常找誰？如果申訴對象就是這個窗口呢？ | 哪些人應看到原文？哪些只需知道有待協調事項？ |

| Q14 | 您如何判定可以結案？ | 家屬未讀、轉介未確認或仍有照護事項時，各怎麼處理？ |
| Q15 | 現有紀錄中，哪些欄位會在多個系統重複填寫？ | 以欄位名稱或空白範本說明即可，不開真實個案。 |
| Q16 | 若系統或通訊中斷，現在靠什麼讓工作接續？ | 恢復後誰核對責任與是否重複送出？ |
| Q17 | 哪些通知會需要立即看、哪些會造成干擾？ | 提醒條件由誰決定，無回應後實際由誰處理？ |
| Q18 | 這份流程最可能在哪個班別或情境失效？ | 請提出替代方案及下一次可以怎麼驗證。 |

## SOP核對清單

每項填「已確認／有衝突／不適用／待確認」，附依據代碼與確認者。訪談口述先記為口述，未經指定窗口確認不升格成已核定SOP。需要查看內部文件時由機構在其環境核對版本及條款，對外只保留可分享的結論或空白欄位。
