# 一般護理之家流程與權限訪談包

版本：2026-10-25，台灣時間。程式基準為 main `b7c771a40ad3a6046a9a7b68c8cb5042b39642e3`，已包含 PR #4。本輪交付研究與規格，不修改應用、權限、資料庫、HITL 核心或原論文成果。

這份文件包讓一般護理之家的人員使用虛構案例，指出實際職責、資訊需求、交接方式及例外處理。尚未訪談任何機構，沒有將設計稿認定為院方 SOP、法令符合性或產品驗收結果。機構類型以護理人員法下的一般護理之家為主；其他住宿式長照、老人福利、日照及居服制度不直接套用。

## 證據標記

| 標記 | 意義 | 可以支持的判斷 |
| --- | --- | --- |
| L | 官方現行法規與施行狀態 | 對應條文範圍；不由條文推導某個帳號應開哪些按鈕。 |
| A | 官方特定年度評鑑資料 | 該年度評鑑內容；與法律條文明確分開。 |
| P | 廠商官網公開自述 | 公開功能或工作物件；未確認的時序、權限或 API 保持未知。 |
| R | 固定程式基準的可讀實作 | 目前本機示範功能，與正式部署分開。 |
| D | 研究者提出的設計或推論 | 可反駁、可比較的方案，沒有自動生效。 |
| S | 機構待確認事項 | 須取得機構證據、負責人及決定，不能預填「符合」。 |

各表未標 L／A／P／R 的候選分工與規格均屬 D＋S。來源編號如 L01、P02 見 SOURCES；制度核對問題如 S01 見 SOP 清單；任務如 U01 見驗收腳本。

## 本輪範圍與不可混用的狀態

現有 R：護理師處理授權住民案件；指定護理師接受後才交班；護理長唯讀監控；照服員讀照護資料及回報觀察；IT 管理授權。社工、行政、機構負責人的獨立操作角色、停權生命週期、申訴專案、代理及改派均未實作。

未實作功能使用紙本／文件情境卡。不能把社工或行政登入成護理師來假裝新角色已完成，不能以 IT 帳號代替護理長，也不能在訪談時開通真實 LINE 或匯入現場資料。所有候選能力預設不啟用；沒有機構同意不擴大護理長唯讀權限。
