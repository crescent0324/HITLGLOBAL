L01 第19-1條的「代理超過一個月應備查、最長一年」只用於該條所指負責護理人員的職務代理。它不是家屬詢問、一般交班、臨時代班或申訴的法定回覆期限。普通案件的提醒、回覆目標、休假與夜間計算方式均留 S05／S10 確認。

法規資料庫頁面顯示資料整編截止 115-10-16；施行狀態與主管機關最新公告可能另有更新。正式採用由機構法遵／負責窗口核對具體類型、資格、契約及所在地要求。本文件提出訪談問題與系統候選設計，沒有代機構作法律適用認定。
