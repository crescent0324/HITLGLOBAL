# 現場訪談與SOP確認

沿用 [原訪談Q01～Q18及S01～S26](../institution-workflow/SOP_VALIDATION_CHECKLIST.md)，不另建立重複問題庫。正式開始前由機構確認參與自願、可跳題／退出、匿名代碼、保管者、可讀者、期限與退出後資料處理。筆記、錄音、畫面各自取得同意；未同意即不收該項資料。對外論文研究另循所屬機構倫理程序，不自行宣告免審。

## 開場可直接朗讀

「今天測試的是虛構環境和操作方式，不考核個人。帳號、住民及家屬都不是真實資料。請邊做邊說你認為現在誰負責、下一步是什麼。卡住、想退出或不想回答都可以。請不要描述可辨認的真實個案。你的意見只在剛才同意的範圍內記錄。」

先問Q01、Q02、Q15，讓人員敘述現行做法，再開始計時操作。不要先講系統的標準答案。U01～U08後問Q04～Q06、Q14、Q16；U09～U20依卡片連回Q07～Q13、Q17～Q18。人員疲累可分場，未做項目保留未執行。先前60～75分鐘只是場次建議，不能要求趕完二十項才算同意參與。

## 卡片的固定追問

1. 實際由哪個職務提出、誰有權核准、誰明確接收？三者是否同人？中間誰安排實際工作？
2. 你剛才描述的是自己的習慣、同事共同做法，還是正式規定？請機構在其環境核對文件代碼、版本及適用班別，不需提供內部全文。
3. 若此人休假、失權、沒有回應或就是申訴對象，下一步實際可找誰？沒有依據時記未知，不誘導回答「交給護理長」。
4. 現行電話、紙本或ERP如何處理？多一套登錄會增加哪些重工？哪些欄位不用看也能完成？
5. 請提出一個這套候選流程會失效的反例，以及可在下一場驗證的方法。

提示分三層逐次記錄：請重讀任務→指出所在區域→說明具體操作。第一次具體提示後，該次就不能列獨立完成。不要為了讓流程完成而借帳號、臨時擴權或填真實資料。

## 結尾與確認

讀回已觀察事實、原話、研究者推測、機構待確認四項，請對方修正。沉默不當同意。SOP口述先標待核定，指定窗口確認後才升格；保留意見不同的職務與班別。將匿名證據代碼、S編號與M0～M3需求連起來，不公布可識別人員的抱怨或評分。正式機構驗收與學位研究資料同意分開記錄。
