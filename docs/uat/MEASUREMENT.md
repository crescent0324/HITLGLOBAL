# 觀察與分析定義 v0.3

在第一位實際參與者前，主持人與機構窗口填寫：核定日期______、版本______、任務清單______、確認紀錄位置______。若改定義，升版本並分開報告，不回改舊紀錄。這是本UAT量測協議，與原論文治理實驗的假設、指標及歷史結果分開。

## 每列與欄位

[CSV](OBSERVATION_TEMPLATE.csv)以UTF-8 BOM、逗號、單列標頭保存。每列＝一位匿名參與者在一場的一個情境的一次嘗試。多角色任務每人各一列；共同案件可在證據代碼關聯。同一人重試新增列、嘗試次數加一，不能覆寫失敗列。20列僅預填情境及未執行，其他空白不代表零。

| 欄位 | 固定定義與填法 |
| --- | --- |
| 協議版本、場次代碼、匿名代碼 | v0.3、啟動視窗的S代碼、機構另配P代碼；真名對照若必要由機構另控，不放本表。 |
| 職務、班別 | 受訪職務及日／夜／其他／不提供；小樣本避免可識別的詳細組合。 |
| 情境ID、嘗試次數、模式 | U01～U20、正整數；系統／紙卡。U09～U20本輪全部紙卡。 |
| 證據類型 | 真人／開發者／自動化。分析真人時排除後兩者，不混成樣本數。 |
| 開始時間、結束時間、暫停秒數 | ISO8601含時區，如2026-10-25T16:00:00+08:00；同一時鐘。讀完任務、說「開始」時計時，到完成、放棄或中止結束。正常思考、操作等待、提示與系統失敗都計入；非任務中斷另記暫停理由與秒數。 |
| 完成狀態 | 未執行／獨立完成／提示後完成／未完成／中止／不適用。不適用必填理由；中止保留原因。紙卡完成表示走完討論，不代表SOP核准或功能通過。 |
| 提示次數 | 主持人提供定位、按鈕、順序或答案的一次連續提示算1；純朗讀任務、請繼續說明不算。開始後每次具體提示都記，提示內容寫備註。 |
| 操作錯誤次數 | 一次可辨認的非預期動作或錯誤路徑算1，連續同原因重按合併一次並記次數細節；成功觸發U03過時拒絕、U08撤權是預期結果，不算參與者錯誤。系統缺陷另標，不把它算成操作錯誤。 |
| 實際結果、困難、原始回饋、觀察備註 | 前兩項記可見行為；回饋保留原話並去識別，研究者解讀放備註。不要把自己推測寫成參與者原話。 |
| 系統缺陷、SOP不明確 | 是／否／待確認；可以同時是。程式偏離已實作契約須可重現才確認缺陷；沒有正式流程證據就保持SOP待確認。 |
| 容易程度1至5、工作負擔1至5 | 結束後自評：容易程度1很難～5很容易；工作負擔1很低～5很高。可拒答留空，兩者方向不同，不合併成總分。不是標準化SUS／NASA-TLX，也不推論臨床成效。 |
| 重複登打次數 | 同一任務同一資訊因跨畫面／系統需再次輸入算1；指出欄位及目的，必要的確認不自動當重工。 |
| 責任人回答、理解判定 | 先記本人回答；對照HITL_EVALUATION為正確／部分／錯誤／未評估。提示前後分開，不能只留提示後正解。 |
| 院內依據、提出者、核准者、接收者 | 院內依據＝個人習慣／機構口述待核定／正式依據已核對／未知；另三欄填職務或代碼，不必填真名。無此角色填無／待確認，不能默認最高主管。 |
| 證據代碼、待改善、協議偏離 | 指向核准保管處的匿名筆記／畫面，不附真實個案；改善與證據分開。臨時改任務或準備失敗記偏離，不能悄悄換成功條件。 |

有公式起始字元的原話（=、+、-、@）在CSV工作副本前加單引號以文字匯入，原始筆記另按同意範圍保留。含逗號、引號或換行的欄位用CSV引號規則，不手工拼接未跳脫內容。編輯後檢查中文、欄數與換行；不直接用文字編輯器做分析。

## 預先固定的成功條件與分母

U01～U08以TEST_SCENARIOS各項可見安全結果全部成立為操作完成；獨立完成還要求提示次數為0。資料越權、責任誤轉、真實資料輸入或無法識別承接缺口，立即中止該任務並保留紀錄。可用性達標比例、招募數及最長場次由機構事前核定，這裡不捏造門檻或理想改善百分比。未核定時只能探索，不能給正式通過結論。

- 主要分析用真人、各人各情境的第一次嘗試；重試另外報告。U01～U08操作與U09～U20紙卡分開。
- 實際執行分母＝獨立完成＋提示後完成＋未完成＋中止；未執行、不適用不入分母，但各自列數量及原因。準備失敗另報，不能藏掉它造成的無法執行。
- 獨立完成率＝獨立完成／實際執行；提示後完成另列；總完成率＝（獨立＋提示後完成）／實際執行。分母0顯示「尚無資料」，不能填0%或100%。
- 每情境、職務、班別分別呈現n／N，不將不同任務加總偽裝成獨立受試者數；小樣本只做描述，不推論全院。
- 耗時＝結束減開始減有理由暫停秒數；缺時間、結束早於開始或暫停超過總時間標為待核對，不補0。獨立完成、提示後完成、未完成的耗時分開報中位數與範圍，並列有效／缺漏數，不只保留最快成功者。
- 錯誤、提示、重工報計數及分布；容易與負擔為序位評分，分開報各分數人數、有效／未答數，必要時中位數，不主張差一分代表固定效果。
- 原話→可見問題→系統缺陷／理解／SOP／環境→現行替代→M候選。保留反例與不需要新功能的意見，不按主管職稱加權。

現在沒有真人紀錄，所有率、耗時、評分及產品方向一律「尚未驗證」。本包只提供定義和空表，不產生虛構成效報表。
