# 來源與證據登錄

研究基準：2026-10-23。實際查閱：2026-10-24（台灣時間）。

本登錄的支持內容均為研究者摘要。功能「已確認支援」代表有產品特定的公開宣告或可觀察元件，未代表已登入實測。廠商宣稱的省時、效率、市占及客戶數均未當作獨立效果。

無發布日期的網頁，只能證明查閱日狀態，無法保證基準日前一天的內容相同。未找到基準日後發布且需要納入的功能；無日期資訊仍保留回溯限制。

來源強度依序考慮官方文件／教材、政府、導入機構、專業研究與具名使用經驗；平台刊載廠商稿件仍屬廠商說明。兩個網域轉載同一稿件不視為獨立實測。

## 使用方法

各文件的來源編號連到本頁；[機器可讀來源表](SOURCE_CATALOG.csv)另保留產品支持範圍、查閱日期、可存取性及 HTTP 回應內容的 SHA-256。雜湊只識別本次取得的位元組，不證明內容真實，也不保證動態頁能重現相同雜湊。未重新散布廠商整頁內容或原始介面素材。

## 衝突與排除規則

| 項目 | 差異 | 本研究處理 |
| --- | --- | --- |
| Jubo 家屬入口 | J13 使用 App 名稱；J18 指定安心寶 2.0 以 LINE 為入口 | 明列版本及日照範圍，沿用 App 名稱不推論獨立安裝要求 |
| uCare ISO | U01／U07 是 2013 版歷史資訊，U11 提及 2022 與 27701 標準 | 公開宣告存在；證書有效期、驗證單位、涵蓋範圍未確認 |
| uCare AI | U10 是預告，U11 具體提及 AI 語音；U09 是另售方案 | 語音紀錄依 U11；CRM 升級仍留版本缺口，OIC 等不直接算內建 |
| CareOne 指標與診斷 | C05 含 2017 資料與六大指標；C02 授權為 2015～2017 | 歷史能力線索；2026 模組、指標及授權版本另行未確認 |
| 同名產品 | 美國 UCare 保險、宇康醫電、祐康醫材及 ECare | 全部排除，與本研究 uCare／CareOne 無法等同 |
| uCare 居服傳輸及刪除 | U13 App 商店寫資料未加密／無法刪除；U11 提及傳輸加密，U12 可申請刪除 | 保留來源、App 範圍與日期差異，不宣稱整套不安全或已全面加密；待廠商提供具體傳輸與刪除證據 |
| 指標與評鑑 | 廠商九大指標、舊簡報六大指標、G04 年度評鑑 | 分開保留；沒有以數量排名或宣稱保證評鑑合格 |
