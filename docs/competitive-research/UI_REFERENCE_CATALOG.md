# 介面、展示與操作教材目錄

查閱：2026-10-24。此處是本輪合理公開搜尋與產品頁遍歷範圍內，已找到的介面證據清單，不宣稱涵蓋整個網際網路或登入後所有教材。

每列保留產品、來源、畫面、日期／版本、角色、直接可觀察元件、未知與設計參考。原圖以來源連結提供，未重新散布完整素材。網址仍可因廠商更版而失效；[UI_EVIDENCE.csv](UI_EVIDENCE.csv)提供同內容的機器可讀版。

官方公開畫面多為裁切或行銷組合，能證實元件與資料呈現，不證明保存、簽核、錯誤處理及後端權限。示例時間不是版本發布日。角色附「情境」者為研究者推定用途，非官方預設角色。
