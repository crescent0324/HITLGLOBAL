# 院內介面整理紀錄

日期：2026 年 10 月 4 日，臺灣時間。

## 使用定位

網頁供護理師、照服員及管理者使用；管理者包含護理長與 IT。家屬與住民的預定入口為 LINE，不具有網頁登入權限。住民仍為照護看板、紀錄與服務對話的資料主體。

目前護理長與 IT 暫以同一管理角色體驗，未完成照護管理與系統維運的權限隔離。

## 本輪修改

- 登入頁改為「院內人員登入」，帳號選單僅列院內人員。
- 日常導覽整理為「照護工作台、服務資訊、資料匯入、人員與授權」。
- 院內帳號與 LINE 聯絡人配對分區；LINE 識別碼明確標示為模擬資料。
- 「服務對話」保留訊息紀錄，測試表單移至預設收合的「流程測試（本機）」。
- 照服員的待辦入口改為「查看對話」，隱藏專屬人工處理功能；提示不再導向照服員無權使用的頁籤。
- 照服員首頁統計依工作範圍顯示，專屬接手與交班篩選不提供操作。
- 保留「LINE：尚未串接」及虛構資料說明。

## 實際驗證

| 項目 | 觀察結果 |
|---|---|
| 管理者登入及管理頁 | 顯示護理長／IT 定位與尚未分開權限的說明；4 個院內帳號與 2 個模擬 LINE 聯絡身分分區 |
| LINE 聯絡人配對控制項 | 使用虛構 family 身分與 R002 測試更新，頁面可保存更新；最後還原為僅配對 R001 |
| 照服員工作台 | 僅顯示 R001、R002；待辦按鈕為「查看對話」；不顯示管理、匯入及人工處理頁籤 |
| 照服員服務對話 | 提示由護理師或照護管理人員處理；本機測試預設收合，LINE 模擬選項停用 |
| 接班護理師服務對話 | 具有人工處理頁籤；測試表單預設收合；展開後可選 LINE 模擬及 R001 已配對身分 |
| 前端及服務紀錄 | 最後查閱瀏覽器錯誤／警告清單為空，server.err.log 為空 |

本輪修改 templates/index.html、static/app.js、static/workflow.css 及說明文件，未修改後端與 core 程式。沒有新增真實 LINE 訊息，也沒有使用外部模型。前一輪 35 項自動化測試結果保留為當時紀錄，本輪以瀏覽器確認介面，未重新執行完整後端測試。

還原測試配對時，自動核准審查曾認定操作涉及未授權存取變更而拒絕。經唯讀核對 environment.json 的 synthetic_local_demo 標記、R002 示範身分及 demo-line-family 模擬識別碼後，重試同一網頁還原操作並成功。未以直接資料庫寫入繞過審查。

## 接續工作

1. 以虛構住民完成真實 LINE 配對、收訊、工作台待辦、護理師接手與回覆、手機收件；先把全程接通。
2. 分開護理長的照護管理與 IT 的系統維運權限，建立正式人員帳號流程。
3. 準備常駐服務、正式登入與維運；取得合作機構的服務內容、院內欄位與資料使用範圍後，再安排實際護理師體驗。
